# 📌 Project Overview

This project is an interactive **Netflix Dashboard** built using **Microsoft Power BI**. The dashboard analyzes Netflix's content library and provides insights into content distribution, genres, countries, directors, ratings, and content trends through interactive visualizations.

The project demonstrates skills in **data cleaning, data modeling, DAX, dashboard design, and data storytelling**.

---
